# Artilex — Catálogo web

Sitio estático del catálogo de **Artilex Parfum**, una perfumería de fragancias de inspiración. Presenta 114 fragancias con su silueta y ficha de detalle.

## Características

Catálogo navegable de 114 fragancias construido como sitio estático (HTML, CSS y JavaScript), sin backend ni dependencias. Incluye ficha de detalle por producto y diseño responsive para móvil y tablet.

## Stack

HTML · CSS · JavaScript

## Estructura

**index.html** — página principal del catálogo

**perfume.html** — ficha de detalle de cada fragancia

**datos/** — datos de las fragancias

**css/, js/, siluetas/** — estilos, lógica y recursos gráficos
